# データインポート

Zilliz Cloud は、AWS S3、GCP Storage、Azure Blob Storage などの様々なストレージオプション、および Parquet (推奨)、JSON、NumPy ファイルなどの形式からのデータインポートをサポートしています。この章では、これらのストレージオプションからサポートされている形式でデータをインポートする手順を説明します。
