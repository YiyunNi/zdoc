        ## オートスケーリングのアップグレード\{#autoscaling-upgrade}

        **Zilliz Cloudのオートスケーリング機能に大幅なアップグレードを導入し、** より優れた自動リソース管理エクスペリエンスを提供できるよう進化します。主な改善点は以下の通りです。

        - **インテリジェントなオートスケーリング:** スケールアップのためのキャパシティしきい値を手動で設定する必要がなくなります。当社のシステムは、リアルタイムのワークロード需要に基づいて最適なパフォーマンスとリソース利用率を自動的に確保します。

        - **自動スケールダウンのサポート:** 多くの要望があった機能がついに登場します！新しいオートスケーリングは、負荷が低い期間に自動スケールダウンをサポートし、手動介入なしでコストを最適化します。

        - **簡素化された設定:** 最小および最大のCUサイズを設定するだけでよくなります。Zilliz Cloudは、可用性とリソース利用率のバランスを取るために、これらの境界内でスケーリングを自動的に管理します。

        ## 監査ログのGA\{#audit-log-ga}

        このリリースで、**監査ログのGA（一般提供）** を発表できることを嬉しく思います。現在、**3つのクラウドプロバイダーすべて**（AWS、GCP、Azure）でホストされているクラスターがサポートされています。

        VectorDB監査ログは、クラスター内のユーザーアクティビティの詳細な記録を提供し、**セキュリティの向上、コンプライアンスの確保、問題のトラブルシューティング**をより効率的に行うのに役立ちます。クエリ/検索からデータ管理操作、接続イベントからユーザーまたはロールの変更まで、操作の完全な可視性により、監査ログは**データアクセスを監視**し、異常な動作を検出し、**企業のガバナンスとコンプライアンス要件を満たす**ことを可能にします。

        GA以降、監査ログは**有料機能**となります。有効にするには、**Enterprise Plan**で**専用クラスター**を選択してください。

        - 使用方法の詳細については、[VectorDB監査ログユーザーガイド](./audit-logs)を参照してください。

        - 料金情報については、[料金ガイド](./understand-cost)を参照してください。

        ## SSOエクスペリエンスの改善\{#improved-sso-experience}

        このリリースにより、Zilliz CloudのSSOセットアッププロセスが改善され、設定がよりシンプル、高速、かつエラーの少ないものになりました。

        **ハイライト:**

        - **IdP固有のフロー**: **Okta**(OIDC, SAML 2.0)、**Microsoft Entra**(SAML 2.0)、**Google Workspace**(SAML 2.0)向けに、コンソールと[ドキュメント](./single-sign-on)の両方でカスタマイズされたガイダンスを提供します。

        - **より良いUX**: より明確なフィールドマッピングと証明書アップロードの検証により、設定ミスを防ぎます。

        - **強化されたドキュメント:** **視覚的なIdP固有の例**により、Zilliz UIとIdP管理コンソールを頻繁に切り替える必要がなくなります。

        ## 強化機能\{#enhancements}

        - SDK（Python、Java）を通じてステージのライフサイクル全体を管理できるようになりました。SDKを介してステージを作成した後、ファイルをシームレスにアップロードし、ワークフローを処理できるため、開発がよりスムーズかつ効率的になります。

        - GUIを通じてParquet形式のローカルファイルを直接インポートできるようになりました。これにより、JSON以外のサポートされる形式がさらに拡張され、大規模なデータセットの操作が容易になり、データオンボーディングプロセスが効率化されます。

        - Milvusバックアップファイルからの移行で、特定のデータベースとコレクションを選択できるようになり、オンプレミスのMilvusからクラウドにデータを転送する際の柔軟性と精度が向上しました。

        - Zilliz GUIでコレクションに関連付けられているすべてのエイリアスを表示できるようになり、エイリアス使用状況の管理と追跡が容易になりました。

        - ZillizのTerraform ProviderがBYOCインスタンス管理をサポートするようになりました。Terraformを使用して、BYOCプロジェクト内でインスタンスを作成、更新、削除できます。

        - 使用状況がCSVへのエクスポートをサポートするようになり、ユーザーエクスペリエンスが向上し、データの分析とアーカイブが容易になりました。

        - 請求プロファイルのメールアドレスで請求通知を受け取れるようになり、財務チームが常に最新情報を把握できるようになりました。
