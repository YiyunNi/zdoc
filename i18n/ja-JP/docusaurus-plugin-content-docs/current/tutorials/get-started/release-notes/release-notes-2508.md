        ## オートスケーリングのアップグレード\{#autoscaling-upgrade}

        **Zilliz Cloudのオートスケーリング機能に大幅なアップグレードを導入し、**より優れた自動リソース管理エクスペリエンスを提供できるよう進化します。主な改善点は以下のとおりです。

        - **インテリジェントなオートスケーリング:** スケールアップのための容量しきい値を手動で設定する必要がなくなります。当社のシステムは、リアルタイムのワークロード需要に基づいて、最適なパフォーマンスとリソース利用率を自動的に確保します。

        - **自動スケールダウンのサポート:** 多くの要望があった機能がついに登場しました！新しいオートスケーリングは、負荷の低い期間に自動スケールダウンをサポートし、手動介入なしでコストを最適化します。

        - **簡素化された設定:** 最小および最大のCUサイズを設定するだけでよくなりました。Zilliz Cloudは、これらの境界内でスケーリングを自動的に管理し、可用性とリソース利用率のバランスを取ります。

        ## 監査ログのGA\{#audit-log-ga}

        このリリースでは、**監査ログ**の**GA（一般提供）**を発表できることを嬉しく思います。現在、**3つのクラウドプロバイダーすべて**（AWS、GCP、Azure）でホストされているクラスターがサポートされています。

        VectorDB 監査ログは、クラスター内のユーザーアクティビティの詳細な記録を提供し、**セキュリティの向上、コンプライアンスの確保、問題のトラブルシューティング**をより効率的に行うのに役立ちます。クエリ/検索からデータ管理操作、接続イベントからユーザーまたはロールの変更まで、操作を完全に可視化することで、監査ログは**データアクセスを監視**し、異常な動作を検出し、**エンタープライズガバナンスとコンプライアンス要件を満たす**ことを可能にします。

        GA以降、監査ログは**有料機能**となります。有効にするには、**Enterprise Plan**で**専用クラスター**を選択してください。

        - 使用方法の詳細については、[VectorDB 監査ログユーザーガイド](./audit-logs)を参照してください。

        - 料金情報については、[料金ガイド](./understand-cost)を参照してください。

        ## SSOエクスペリエンスの向上\{#improved-sso-experience}

        このリリースでは、Zilliz CloudのSSOセットアッププロセスを改善し、設定をよりシンプル、迅速、かつエラーが発生しにくいものにしました。

        **ハイライト:**

        - **IdP固有のフロー**: コンソールと[ドキュメント](./single-sign-on)の両方で、**Okta**(OIDC, SAML 2.0)、**Microsoft Entra**(SAML 2.0)、および**Google Workspace**(SAML 2.0)に合わせたガイダンスを提供します。

        - **UXの向上**: より明確なフィールドマッピングと証明書アップロードの検証により、設定ミスを防ぎます。

        - **強化されたドキュメント:** **視覚的なIdP固有の例**により、Zilliz UIとIdP管理コンソールを頻繁に切り替える必要がなくなります。

        ## 拡張機能\{#enhancements}

        - **SDK（Python、Java）を通じてステージのライフサイクル全体**を管理できるようになりました。SDKを介してステージを作成した後、ファイルをシームレスにアップロードし、ワークフローを処理できるため、開発がよりスムーズで効率的になります。

        - **GUI**を通じて**Parquet形式のローカルファイル**を直接インポートできるようになりました。これにより、JSON以外のサポート形式がさらに拡張され、大規模なデータセットの操作が容易になり、データオンボーディングプロセスが合理化されます。

        - **Milvusバックアップファイルからの移行**が、特定の**データベースとコレクション**の選択をサポートするようになり、オンプレミスMilvusからクラウドへのデータ転送時に、より柔軟性と精度が得られます。

        - Zilliz GUIでコレクションに関連付けられている**すべてのエイリアス**を表示できるようになり、エイリアス使用状況の管理と追跡が容易になりました。

        - ZillizのTerraform ProviderがBYOCインスタンス管理をサポートするようになりました。Terraformを使用して、BYOCプロジェクト内でインスタンスを作成、更新、削除できます。

        - 使用状況がCSVへの使用状況詳細のエクスポートをサポートするようになり、ユーザーエクスペリエンスも向上し、データの分析とアーカイブが容易になりました。

        - 請求プロファイルのメールアドレスで請求通知を受け取れるようになり、財務チームが常に最新情報を把握できるようになりました。
