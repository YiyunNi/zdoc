# リリースノート (2023年4月6日)

Zilliz Cloudの最新アップデートを発表できることを大変嬉しく思います。今回のアップデートでは、コスト見積もり用の料金計算ツール、データセキュリティを強化するためのデータバックアップおよび復元プロセス、グローバルユーザー向けのカスタマイズ可能なタイムゾーン設定、より良い整理のためのコレクション名変更ツール、無制限の使用のためのストレージクォータの削除、および非アクティブなデータベースのクレジット節約の改善が特徴です。

- 料金計算ツール

    新機能「料金計算ツール」のリリースを発表できることを嬉しく思います。この新機能は、ユーザーがコストを効果的に計画し、見積もるのに役立つように設計されています。料金計算ツールを使用すると、ユーザーはCUタイプを簡単に選択し、エンティティ数とベクトル次元を入力するだけで、Zilliz Cloudの推奨CUサイズとコスト見積もりを取得できます。[こちらをクリック](https://zilliz.com/pricing#calculator)してお試しください。

    当社の料金計算ツールは現在ベクトルデータのみをサポートしていますが、将来的にはスカラーデータを含めるように機能を拡張し、ユーザーにより正確なコスト見積もりを提供できるよう計画しています。

- GCPでのバックアップと復元

    今回のリリースにより、当社のプラットフォームはGoogle Cloud Platform (GCP)でのデータベースのバックアップと復元をサポートするようになりました。この最新リリースにより、ユーザーはGCPでデータベースを簡単にバックアップおよび復元できるようになり、データ復旧とビジネス継続性が保証されます。

    詳細については、[バックアップと復元](./backup-and-restore)を参照してください。

- カスタムタイムゾーン

    タイムゾーン設定のサポートを追加しました。これにより、ユーザーはタイムゾーン設定をカスタマイズし、すべてのデータで正確なタイムスタンプを確保できます。

    詳細については、[タイムゾーンの管理](./organization-settings#manage-timezone)を参照してください。

- コレクション名の変更

    最新リリースに、データベースコレクションの名前を変更できる新機能が含まれていることをお知らせします。この機能は、ユーザーがデータベース構造をより適切に管理し、新しいコレクションを作成してデータを移行することなく必要な変更を行うのに役立つように設計されています。

- ストレージクォータの削除

    今回のリリースにより、プラットフォームからストレージクォータを削除しました。これにより、ユーザーはストレージ制限を心配することなく、アンロードされたコレクションにデータをインポートできるようになりました。データストレージに制限はありませんが、各データベースのロード容量はデータベースのサイズに依存します。適切なデータベースサイズを選択するために、料金計算ツールを使用することを強くお勧めします。

    さらに、データベースが事前に割り当てられたCUに収まらない場合のユーザー通知も改善しました。データベースが容量を超えた場合、ユーザーは通知を受け取ります。これにより、ユーザーはデータがインポートできなかった理由をよりよく理解し、適切な措置を講じることができます。

- 非アクティブなデータベースのクレジット節約の改善

    非アクティブなデータベースの製品ロジックとリマインダー通知を最適化しました。ユーザーのデータベースが14日間連続で非アクティブであった場合、無料クレジットを節約するために、データベースを自動的に停止します。データセキュリティは常に最優先事項であるため、非アクティブなデータベースからデータを削除することはありません。データベースが停止されたユーザーは、いつでも再開できます。さらに、この最適化を含めるように利用規約を更新しました。

- その他の改善点

    - 請求のUIを改善しました。

    - CUタイプの名称を更新しました。「High Performance」は「Performance-optimized」に、「Big Data」は「Capacity-optimized」に名称変更されました。
