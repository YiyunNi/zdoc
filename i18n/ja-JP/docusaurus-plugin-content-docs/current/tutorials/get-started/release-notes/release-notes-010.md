# リリースノート (2023年1月10日)

Zilliz Cloud の重要なアップデートが一般公開されたことをお知らせいたします。このリリースでは、データプレビュー機能と、コンソールでコレクションに簡単にインポートできるデモデータセットが追加されました。

- データプレビュー

    このリリースでは、Zilliz Cloud はデータプレビュー機能を提供します。各コレクションページに**データプレビュー**機能タブがあります。プレビューテーブルでは、コレクション内のサンプリングされたエンティティセットのすべての値を表示でき、データの検証が容易になります。

    データプレビュー機能に加えて、プレビューテーブル内の任意のベクトルを選択し、それをクエリベクトルとして使用できます。これにより、コレクション内の近傍データを迅速に検証できます。

- デモデータセット

    Zilliz Cloud は、ベクターデータベースの機能に慣れるためのデモデータセットを提供するようになりました。このデモデータセットは Kaggle データセットから派生したものです。2020年1月から2020年8月の間に主要な出版物で公開された5,000以上の記事の詳細が含まれています。

    これで、データ準備に余分な労力を費やすことなく、ベクターデータベースの全機能を簡単に体験できます。[ぜひお試しください！](https://cloud.zilliz.com/signup)
