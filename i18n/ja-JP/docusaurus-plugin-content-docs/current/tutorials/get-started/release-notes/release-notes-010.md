# リリースノート (2023年1月10日)

Zilliz Cloud の重要なアップデートが一般公開されたことをお知らせいたします。このリリースでは、データプレビュー機能と、コンソールでコレクションに簡単にインポートできるデモデータセットが追加されました。

- データプレビュー

    このリリースでは、Zilliz Cloud はデータプレビュー機能を提供します。各コレクションページで**データプレビュー**機能タブを見つけることができます。プレビューテーブルでは、コレクション内のサンプリングされたエンティティセットのすべての値を表示でき、データの検証が容易になります。

    データプレビュー機能に加えて、プレビューテーブル内の任意のベクトルを選択し、それらをクエリベクトルとして使用できます。これにより、コレクション内の近傍データを迅速に検証できます。

- デモデータセット

    Zilliz Cloud は、初心者がベクトルデータベースの機能に慣れるのに役立つデモデータセットを提供するようになりました。デモデータセットは Kaggle データセットから派生しています。2020年1月から2020年8月の間に主要な出版物で公開された5,000以上の記事の詳細が含まれています。

    これで、データ準備に余分な労力を費やすことなく、ベクトルデータベースの全機能を簡単に体験できます。[お楽しみください！](https://cloud.zilliz.com/signup)
