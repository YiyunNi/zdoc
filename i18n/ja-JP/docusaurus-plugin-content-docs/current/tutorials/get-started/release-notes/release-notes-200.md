# リリースノート (2023年6月11日)

Zilliz Cloudのリリースは、ベクトルデータベース管理に新たな標準を確立します。初心者向けのユーザーエクスペリエンスを大幅に向上させ、より手頃で柔軟な料金オプションを提供し、シームレスなチームコラボレーションを可能にし、柔軟なスキーマ管理を提供します。このアップデートの主な機能には、サーバーレスクラスター、多様なティアプラン、組織とコラボレーションのサポート、RBACのサポート、パーティションキー、動的スキーマ、JSONタイプのサポートが含まれます。この画期的なアップデートを今すぐお試しください！

## Milvus互換性\{#milvus-compatibility}

このリリースは**Milvus 2.1.x**と互換性があります。

## Zilliz Cloudサーバーレスベクトルデータベースサービスの開始\{#zilliz-cloud-serverless-vector-database-service-launch}

Zilliz Cloudのサーバーレスベクトルデータベースサービスの開始を発表できることを嬉しく思います。この新しいサービスは、当社の専用クラスターソリューションと比較して、さらに手間のかからないベクトルデータ検索体験を提供します。

初期段階のベンチャー企業をサポートするため、サーバーレスサービスの一部として2つの無料コレクションを提供しています。各コレクションは、768次元スケールで500,000個のベクトルを処理する能力を持ち、広範なインフラストラクチャを必要とせずに実質的なデータ処理能力を提供します。当社の革新的な新機能を試して、今日のデータ処理能力を向上させてください。[無料トライアル](./free-trials)。

## Zilliz Cloudのプランティア：Starter、Standard、Enterprise、およびSelf-hosted\{#zilliz-clouds-plan-tiers-starter-standard-enterprise-and-self-hosted}

Starter、Standard、Enterprise、およびSelf-hostedの幅広いプランティアを提供できることを嬉しく思います。各ティアは、コスト、サービス、およびセキュリティの考慮事項のバランスを取るように設計されており、すべてのユーザーがニーズを満たすプランを持っていることを保証します。Zilliz Cloudを使用すると、ビジネスの成長に合わせてベクトルデータベース管理を柔軟に拡張および進化させることができます。

- Starterプラン：サーバーレスインスタンスで完全に管理されたベクトルデータベースを体験する最も簡単な方法です。最小限の構成で済み、GCPで利用できます。

- スタンダードプラン：5人未満のエンジニアと複雑なワークロードを持つチーム向けに設計されています。高度なデータベース機能と構成を備えた専用クラスターと、優れたコスト効率を提供します。AWSとGCPの両方で利用できます。

- Enterpriseプラン：高度なセキュリティとサポートのニーズを持つ大規模組織向けに設計されています。フル機能、高可用性、および高度な構成を備えた専用クラスターを提供し、AWSとGCPの両方で堅牢なデータベースソリューションを提供します。

- Self-hostedプラン：プライバシーと規制順守を優先する企業に最適です。仮想プライベートクラウド（VPC）内で自己管理型ベクトルデータベースサービスを提供し、完全な制御を提供します。プライバシーと規制順守を優先する環境に適しています。

[料金ページで詳細をご覧ください。](https://zilliz.com/pricing)

## 組織、コラボレーション、およびRBAC\{#organization-collaboration-and-rbac}

Zilliz Cloudが、洗練された組織およびメンバー管理機能を提供するようになったことをお知らせします。これにより、複数のユーザーがクラスター、プロジェクト、組織など、さまざまなレベルでシームレスに共同作業できるようになります。

この主要なアップデートは、ロールベースのアクセス制御（RBAC）の統合によってサポートされており、特定のリソースにアクセスできるユーザーをきめ細かく制御できます。これにより、セキュリティと柔軟性の両方が確保され、チームは高いレベルのデータ保護を維持しながら、より効率的に共同作業できます。

この機能強化は、プロジェクトアクセスに対するより優れた制御を提供するだけでなく、共同作業プロセスを合理化し、チームがより安全で組織化された環境でベクトルデータベースを管理しやすくします。この機能を今すぐ試して、Zilliz Cloudで新しいレベルの共同作業効率を体験してください。詳細については、[アクセス制御](./access-control)を参照してください。

## パーティションキー\{#partition-key}

Zilliz Cloud 2.0.0では、パーティションキー機能が導入されました。この機能を使用すると、コレクションを作成するときに特定のフィールドをパーティションキーとして指定できます。エンティティは、パーティションキーの値に基づいてパーティションに格納されます。

この機能は、パーティションキーフィールドの条件が従来のスキャンベースのフィルタリング方法よりも大幅に高速に実行できるため、クエリフィルタリング中に特に役立ちます。基本的に、同じパーティションキーを持つエンティティは物理的にグループ化され、不要なスキャンを回避します。

## 動的スキーマ\{#dynamic-schema}

Zilliz Cloudがバージョン2.0.0から動的スキーマをサポートするようになったことをお知らせします。この主要な機能強化により、多様なビジネス要件に対応する柔軟性が大幅に向上します。ユーザーは、事前に定義された静的スキーマに制限されることなく、動的に変化するフィールドを持つエンティティをコレクションに挿入できるようになりました。

上級ユーザー向けに、動的スキーマと静的スキーマを組み合わせたハイブリッドアプローチをコレクション作成に組み込みました。これにより、ユーザーはスキーマ設計で「必須」フィールドを指定し、高度なインデックス最適化をアクティブ化できます。一方、「オプション」フィールドは動的スキーマメカニズムによってサポートされます。この新しいアプローチは、スキーマの柔軟性を維持しながらクエリパフォーマンスを向上させます。

Zilliz Cloud 2.0.0でこの機能を探索し、データベーススキーマの適応性が大幅に向上するのを目の当たりにしてください。[この機能の詳細はこちら](./enable-dynamic-field)。

## JSONタイプのサポート\{#json-type-support}

最新のアップデートでZilliz Cloudの主要な機能強化を発表できることを嬉しく思います。JSONデータ管理と近似最近傍（ANN）検索機能の統合です。

JSON、またはJavaScript Object Notationは、今日のデータベース管理の世界で不可欠となっている重要なデータ交換形式です。Zilliz CloudにJSONサポートが導入されたことで、JSONデータを簡単に保存および管理できるようになり、データ操作とクエリの無限の可能性が開かれました。

真の力は、これを既存のANN検索機能と革新的に組み合わせることにあります。この組み合わせにより、JSONデータ構造の柔軟性とANN検索の精度を組み合わせた複雑なクエリを実行できるようになり、データベースクエリ機能が大幅に向上します。

これら2つの強力なテクノロジーの相乗効果を1か所で体験し、データ管理とクエリタスクの効率と精度を新たなレベルに引き上げてください。Zilliz Cloudで今日のデータベーステクノロジーの未来に足を踏み入れましょう。[この機能の詳細はこちら](./use-json-fields)。
