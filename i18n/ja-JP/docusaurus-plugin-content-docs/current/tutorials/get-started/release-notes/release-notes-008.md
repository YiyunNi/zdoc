# リリースノート (2022年11月18日)

Zilliz Cloudのメジャーアップデートが一般公開され、招待なしで利用できるようになりました。このリリースでは、容量最適化されたコンピュートユニット (CU) が導入され、データベースあたり最大32 CUまで拡張可能になり、パフォーマンスが向上しました。また、ローカルファイルやAWS S3バケットからのデータインポートが可能になり、自動インデックス機能によりプロセスが簡素化され、QPSとクエリレイテンシーのリソース監視が追加されました。さらに、データベース作成速度が5倍に向上し、ユーザーインターフェースも最適化され、より優れたエクスペリエンスを提供します。

- 一般公開され、Zilliz Cloudへの登録に招待は不要になりました。

- 容量最適化されたCUをサポートします。

- データベースに最大32 CUを割り当てることをサポートします。

- ローカルファイルおよびAWS S3バケットからのデータインポートをサポートします。

- [自動インデックス](./autoindex-explained)をサポートし、インデックスタイプを選択する必要がなくなりました。

- QPSおよびクエリレイテンシーの[リソースモニター](./metrics-and-alerts)の設定をサポートします。

- データベース作成パフォーマンスを5倍に向上させました。

- ユーザーエクスペリエンス向上のため、UIパフォーマンスを最適化しました。
