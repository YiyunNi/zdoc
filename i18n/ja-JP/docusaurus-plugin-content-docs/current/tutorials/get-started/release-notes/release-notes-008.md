# リリースノート (2022年11月18日)

Zilliz Cloudのメジャーアップデートが一般公開されたことをお知らせします。招待なしで誰でも利用できるようになりました。今回のリリースでは、容量最適化されたCompute Unit (CU) が導入され、データベースあたり最大32 CUまで利用可能になり、パフォーマンスが向上しました。また、ローカルファイルやAWS S3バケットからのデータインポートが可能になり、自動インデックスによりプロセスが簡素化され、QPSとクエリレイテンシのリソース監視が追加されました。さらに、データベース作成速度が5倍に向上し、ユーザーインターフェースが最適化され、優れたエクスペリエンスを提供します。

- 一般公開され、Zilliz Cloudへの登録に招待は不要になりました。

- 容量最適化されたCUをサポートします。

- データベースに最大32 CUを割り当てることをサポートします。

- ローカルファイルおよびAWS S3バケットからのデータインポートをサポートします。

- [自動インデックス](./autoindex-explained)をサポートし、インデックスタイプを選択する必要がなくなりました。

- QPSおよびクエリレイテンシの[リソースモニター](./metrics-and-alerts)の設定をサポートします。

- データベース作成パフォーマンスを5倍向上させます。

- ユーザーエクスペリエンス向上のため、UIパフォーマンスを最適化します。
