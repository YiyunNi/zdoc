# リリースノート (2025年1月27日)

Zilliz Cloudは、**パブリックプレビュー**でMilvus 2.5をサポートし、セマンティック検索を補完するフルテキスト検索を導入しました。BM25メトリックとスパースベクトルを使用して効率的なストレージと検索を実現し、ユーザーは変換なしでテキストを直接クエリできます。このアップデートにより、BYOCデプロイメントがPrivate Linkで強化され、セキュリティの向上、コンプライアンスの簡素化、ネットワーク構成の簡素化が図られます。さらに、AWS CloudFormationによる自動デプロイメントがサポートされ、大規模な小規模ファイルインポートの処理が最適化され、データ取り込みが高速化されます。

## Milvusの互換性{#milvus-compatibility}

このリリースは **Milvus v2.4.x** と互換性があります。

クラスターを **パブリックプレビュー** にアップグレードする場合、アップグレード後に **Milvus 2.5.x** の機能が利用可能になります。Zilliz Cloudコンソールの **Cluster Details** ページで **Try Preview Features** をクリックすると、**パブリックプレビュー** の機能について詳しく知ることができます。

## Zilliz CloudがMilvus 2.5をパブリックプレビューでサポートし、フルテキスト検索を導入{#zilliz-cloud-now-supports-milvus-25-in-public-preview-introducing-full-text-search}

Zilliz Cloudは、**パブリックプレビュー**としてMilvus 2.5と互換性を持つようになりました。このアップデートでは、主要な新機能である**フルテキスト検索**（語彙検索またはキーワード検索とも呼ばれます）が導入されます。検索に慣れていない方のために説明すると、フルテキスト検索は、Googleでの検索と同様に、特定の単語やフレーズを検索してドキュメントを見つけることができます。これは、厳密な単語の一致だけでなく、意味の理解に焦点を当てた既存の**セマンティック検索**機能を補完するものです。

当社の実装では、ドキュメントの類似性には**業界標準のBM25**メトリックを使用し、効率的なストレージと検索を可能にする**スパースベクトル**に基づいています。簡単に言えば、スパースベクトルは、ほとんどの値がゼロである方法でテキストを表現します。これは、ごく一部のセルに数値が含まれ、残りが空である巨大なスプレッドシートを想像してください。この効率性は、ベクトルが検索の基盤となるMilvusのコア哲学と一致しています。

当社のアプローチの主な利点は、**事前に手動でスパースベクトルに変換することなく、テキストを直接挿入およびクエリできる**ことです。これにより、Zilliz Cloudは非構造化データ処理を完全にサポートする方向にさらに一歩近づきます。

詳細については、[フルテキスト検索](./full-text-search)を参照してください。

## BYOC - セキュリティの強化とデプロイメントの簡素化{#byoc-enhanced-security-and-simplified-deployment}

このリリースにより、**Zilliz CloudはPrivate Linkを介したデータプレーンとコントロールプレーン間の通信をサポート**し、BYOCデプロイメントの**セキュリティを強化し、コンプライアンスを簡素化**します。

- **セキュリティの強化**: Private Linkは、コントロールプレーン（Zilliz Cloudでホスト）とデータプレーン（お客様のVPCにデプロイ）間のすべての通信が**プライベートネットワーク内**に留まり、パブリックインターネットを完全にバイパスすることを保証します。これにより、**サイバー脅威への露出が減り**、**データ傍受のリスクが排除**されます。

- **コンプライアンスの簡素化**: 多くの企業は、規制基準を満たすために**厳格なデータレジデンシーとネットワーク分離**を必要とします。Private Linkを使用すると、**機密データがお客様のプライベート環境から決して離れない**ことを保証でき、**GDPR、HIPAA、およびその他のセキュリティフレームワーク**への準拠が容易になります。

- **ネットワーク構成の簡素化**: Private Linkは、**複雑なファイアウォールルール、VPN、またはパブリックエンドポイント**の必要性を排除し、運用オーバーヘッドを削減し、BYOCデプロイメントを**よりシンプルで管理しやすく**します。

さらに、**Zilliz Cloud BYOCはAWS CloudFormationを介した自動デプロイメントをサポート**するようになり、データプレーンのセットアップと管理がさらに容易になりました。

詳細については、[AWSへのBYOCのデプロイ](/docs/byoc/deploy-byoc-aws)を参照してください。

## 強化点{#enhancements}

**大規模な小規模ファイルインポートのサポート**: 多数の小規模ファイルを含むインポートの処理が改善され、より高速で効率的なデータ取り込みが保証されます。
