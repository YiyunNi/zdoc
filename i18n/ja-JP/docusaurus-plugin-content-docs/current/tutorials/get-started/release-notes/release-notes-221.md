# リリースノート (2023年9月27日)

Zilliz Cloudのリリースを発表できることを大変嬉しく思います。今回のリリースでは、新しいCUサイズオプションによる柔軟性の向上、前払いサポート、AWSリージョンの追加など、さまざまな機能強化と機能が導入されています。

## Milvus互換性{#milvus-compatibility}

このリリースは **Milvus 2.2.x** と互換性があります。

## クラスターの機能強化 - 新しいCUサイズオプションによる柔軟性の向上{#cluster-enhancements-increased-flexibility-with-a-new-cu-size-option}

新しいクラスターサイズオプションである6 CUにより、クラスター管理がより柔軟になりました。このオプションは、より費用対効果が高く効率的なクラスターオプションを求める、より小規模なデータセットを持つユーザーに最適です。特定のニーズに合わせて調整された、改善されたパフォーマンスを体験してください。

## 前払いサポート{#support-for-advance-pay}

前払いサポートを開始しました。この機能は、利用するサービスに対して前払いを希望するオフライン契約ユーザー向けに特別に設計されています。このオプションを提供することで、お客様の内部財務および調達プロセスを合理化し、貴重なお客様のリスクを最小限に抑えることを目指しています。

お客様またはお客様の組織が特定の要件をお持ちの場合、または前払いオプションについて詳しく知りたい場合は、お気軽に[お問い合わせください](https://zilliz.com/contact-sales)。

## その他のAWSリージョン{#more-aws-regions}

新しいAWSリージョンであるUS East 1 (aws-us-east-1) をサポートすることをお知らせいたします。このリージョンの追加により、ユーザーはこのリージョンでデータ処理機能を強化するために当社のサービスを利用できるようになります。

## その他のハイライト{#other-highlights}

- クレジット有効期限監視機能のUIを強化

- Playground機能のユーザーエクスペリエンスを改善
