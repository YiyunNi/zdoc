# リリースノート (2023年3月6日)

Zilliz Cloud の大幅なアップデートを発表できることを嬉しく思います。このリリースは、使いやすさ、セキュリティ、パフォーマンス、機能性において、ベクトルデータベースサービスの標準を新たな段階に引き上げ、すべての人々のために構築された最先端のベクトルデータベース体験を提供します。

- 10億規模のベクトルコレクションをサポート

    このリリースにより、Zilliz Cloud はベクトルデータベースの容量制限を10億規模にまで押し上げました。これにより、エンタープライズユーザーは Zilliz Cloud のウェブインターフェースを通じて、[32 CU データベースインスタンス](https://zilliz.com/pricing) (パフォーマンス最適化 CU と容量最適化 CU の両方) を作成できるようになりました。

    PoC または本番環境でのデプロイメントにより大規模なインスタンスを必要とするユーザーは、[お問い合わせ](https://zilliz.com/contact-sales)ください。最大256のパフォーマンス最適化 CU (1.3億の128次元ベクトルを処理可能) または128の容量最適化 CU (30億の128次元ベクトルを処理可能) のインスタンスを入手できます。

- パフォーマンスの向上

    このアップデートされたバージョンの Zilliz Cloud は、Milvus 2.2.3 をベースに構築されています。Milvus 2.2.3 により、元の Milvus 2.0.0 リリースと比較して、検索レイテンシを2.5倍削減しました。レイテンシの低減はすべてのユーザーにメリットをもたらしますが、レコメンデーションシステム、画像/ビデオ/テキスト検索、質問応答などのリアルタイム情報検索システムを扱う際には特に重要です。

    同一環境でのテストでは、Milvus 2.2.3 は 2.0.0 と比較して QPS が4.5倍向上しました。この向上により、Milvus はさらにハードウェアとコスト効率が向上し、大規模なベクトル検索プラットフォームを構築する上で不可欠です。

    詳細については、[ホワイトペーパー](https://zilliz.com/resources/milvus-performance-benchmark)をご覧ください。

- GCP 上の Zilliz Cloud

    Zilliz Cloud が Google Cloud Platform (GCP) で利用可能になったことをお知らせします。Zilliz Cloud は、スタートアップから大企業まで、さまざまなユーザーの多様な要件を満たし、最高の体験を提供します。数回クリックするだけで、GCP 上にマネージドベクトルデータベースインスタンスをデプロイできます。

    us-west1 リージョン (オレゴン州ザ・ダルズ) が利用可能になりました。GCP 上の当社のサービスの CU あたりのコストは、パフォーマンス最適化タイプと容量最適化タイプの両方で1時間あたり0.215ドル、ストレージコストは1GBあたり月額0.02ドルです。

- AWS Marketplace

    Zilliz Cloud は [AWS Marketplace](https://aws.amazon.com/marketplace/pp/prodview-iqbidum7feuio) でも利用可能になり、AWS 上で当社のフルマネージドベクトルデータベースサービスにこれまで以上に簡単にアクセスできるようになりました。AI アプリケーションの需要が高まる中、この統合は最高のタイミングで実現しました。AWS Marketplace 上の Zilliz Cloud を利用することで、ユーザーは AI アプリケーションを迅速に構築し、拡張できます。

    この統合の利点の1つは、製品をシームレスに管理できることです。請求、キャンセル、払い戻しなどはすべて、ユーザーの AWS アカウントで管理および追跡できます。この機能だけでも、時間と手間を省き、プロセス全体を合理化します。

    もう1つの利点は、AWS Cost Explorer を通じてコストを表示できることです。このツールを使用すると、費用を簡単に追跡し、請求およびコスト管理プロセスに関する洞察を得ることができます。

    詳細については、[AWS Marketplace で購読する](./subscribe-on-aws-marketplace)を参照してください。

- ローリングアップグレード

    Milvus ユーザーは、システムの健全性を確保するために、定期的にさまざまなメンテナンス作業を実行する必要がありました。しかし、本番システムでのメンテナンス作業はリスクを伴う可能性があります。通常、メンテナンス作業はスケジュールされたダウンタイム中に実行され、データベースをオフラインにし、通常の業務を中断する必要があります。残念ながら、今日のユーザーは長時間のダウンタイムを許容しません。

    良いニュースは、Zilliz Cloud がローリングアップグレードをサポートするようになったことです。Zilliz Cloud にデプロイされたベクトルデータベースを使用すると、スケジュールされたメンテナンスについて心配する必要がなくなります。代わりに、メンテナンスウィンドウを設定し、残りの作業は当社に任せて、ビジネスに集中してください。ほとんどの場合、ローリングアップグレードによるサービスダウンタイムは、1ヶ月あたり1分未満です。

- バックアップと復元

    バックアップと復元機能が Zilliz Cloud で利用可能になりました。データの損失は、ハードウェア障害、ソフトウェアの不具合、さらには人為的なエラーなど、いつでも誰にでも起こり得ます。そのため、データベースの信頼性の高いバックアップと復元ソリューションを導入することが不可欠です。

    新しいバックアップと復元機能を使用すると、データベースを簡単にバックアップし、予期せぬ損失が発生した場合に復元できます。

    詳細については、[バックアップと復元](./backup-and-restore)を参照してください。

- ごみ箱

    データのセキュリティは常に当社の最優先事項です。このリリースでは、Zilliz Cloud にごみ箱を導入し、データをさらに安全にします。たとえば、ユーザーがデータベースを削除したり、無料トライアルでの長期間の非アクティブ化や未払い料金によるサービス停止のために自動的に削除されたりした場合でも、Zilliz Cloud はデータベース/コレクションを自動的にごみ箱に移動し、次の30日間いつでもデータを復元できます。

    詳細については、[ごみ箱を使用する](./use-recycle-bin)を参照してください。

- オープンソース Milvus からのデータベース移行

    このリリースでは、データベース移行ツールキットを導入します。オープンソース Milvus ユーザーは、ローカルデータベースを Zilliz Cloud に簡単に移行できるようになり、システムメンテナンスの負担から解放されます。さらに、移行ツールは Milvus 1.x と 2.x の両方と互換性があります。そのため、Milvus のバージョンに関係なく、わずか2つのステップでデータベースを Zilliz Cloud に簡単に移行できます。

    詳細については、[移行](./migrations)を参照してください。

- その他の素晴らしいアップデート

    新しい請求書ページには、さまざまなリソースの使用状況とサービスの詳細なコスト、クレジットの使用方法、および適用される割引ルールが表示されるようになりました。データプレビューの体験が向上しました。安定性とメモリ使用量を改善するためのいくつかのバグ修正。
