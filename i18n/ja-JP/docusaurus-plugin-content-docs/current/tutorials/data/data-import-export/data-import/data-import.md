# データインポート

Zilliz Cloud は、AWS S3、GCP Storage、Azure Blob Storage などのさまざまなストレージオプションからのデータインポート、および Parquet (推奨)、JSON、NumPy ファイルなどの形式をサポートしています。この章では、これらのストレージオプションからサポートされている形式でデータをインポートする手順について説明します。
