## よくある質問

### AWS、GCP、またはAzureのクレジットを、それぞれのマーケットプレイス経由でサブスクライブした場合に、Zilliz Cloudの使用料と相殺できますか？\{#can-i-use-aws-gcp-or-azure-credits-to-offset-zilliz-cloud-usage-when-subscribed-via-their-respective-marketplaces}

いいえ、AWS、GCP、またはAzureなどのクラウドプロバイダーからのクレジットを、それらのマーケットプレイスを通じてサブスクライブした場合でも、Zilliz Cloudの使用料と相殺することはできません。

Zilliz Cloudの使用料は、各クラウドプロバイダーのマーケットプレイスを通じてサードパーティサービスとして請求され、クラウドプロバイダーが発行するほとんどのプロモーションまたはコミットされた使用クレジットは、自社のネイティブサービスにのみ適用され、サードパーティのマーケットプレイス購入には適用されません。

詳細については、これらのクラウドプロバイダーが提供する規約を参照してください。以下は、それらの規約からの抜粋です。

- [AWS クレジット規約](https://aws.amazon.com/awscredits/): AWS クレジットは、お客様のAWSアカウントに適用され、AWSサービスにのみ有効です。

- [Google Cloud Marketplace 規約](https://cloud.google.com/marketplace?hl=en): GCP クレジットは通常、Google Cloudサービスにのみ適用されます。

- [Azure クレジット使用ガイド](https://learn.microsoft.com/en-us/azure/cost-management-billing/understand/understand-azure-marketplace-charges): Visual Studio およびその他のクレジットは、一般的にサードパーティのマーケットプレイスオファーには適用されません。

### クレジットカードを追加した後、アカウントに残っている期限切れのクレジットを使い続けることはできますか？\{#after-adding-a-credit-card-can-i-continue-to-use-the-expired-credits-left-in-my-account}

はい。アカウントにまだクレジットが残っており、支払い方法を追加している場合、残りのクレジットの有効期限は1年間に延長されます。

### 私の100ドルのクレジットは期限切れになりますか？無料クレジットの有効期限を延長するにはどうすればよいですか？\{#will-my-and36100-credits-expire-how-can-i-extend-the-expiration-of-the-free-credits}

ビジネスメールで初めてアカウントを登録すると、30日以内に使用できる100ドルのクレジットを受け取ります。クレジットの有効期限が近づいたら、支払い方法を追加することで有効期限を延長できます。その後、1年以内に使用できる追加の100ドルのクレジットを受け取ります。

### ごみ箱内のデータは課金されますか？\{#is-data-in-the-recycle-bin-charged}

いいえ。ごみ箱内の削除されたデータに対しては課金されません。
