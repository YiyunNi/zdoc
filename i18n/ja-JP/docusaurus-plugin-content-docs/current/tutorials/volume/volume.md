# ボリューム

ボリュームは、構造化データまたは非構造化データファイルのコレクションのいずれかを格納するオブジェクトストアです。これらのデータ資産にアクセス、保存、管理、および整理するための統一された場所を提供します。この章では、ボリュームとは何か、そのユースケースについて説明し、Zilliz Cloud でボリュームを管理する方法を示します。
