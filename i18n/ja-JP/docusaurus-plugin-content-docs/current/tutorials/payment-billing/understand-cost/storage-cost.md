# ストレージコスト

Zilliz Cloudでは、クラスターが実行されているかどうかにかかわらず、データまたはバックアップファイルを保存するとストレージコストが発生します。

## ストレージコストの発生源{#sources-of-storage-costs}

以下のシナリオでストレージ料金が請求されます。

- クラスターデータストレージ: クラスターに保存されている生データとインデックス。クラスタータイプが階層型ストレージの場合、追加のコールドデータアクセス費用が発生する可能性があります。

- [バックアップ](./backup-and-restore)ストレージ: 災害復旧のために作成するバックアップファイル。

- [ボリューム](./volume-explained)ストレージ: ボリュームに保存されている構造化データまたは非構造化データファイルのコレクション。

## コスト計算{#cost-calculation}

```plaintext
Storage Cost = Storage Unit Price x Data Size x Duration
```

- ストレージ単価: クラウドリージョンとクラスタータイプによって決定されます。詳細な料金については、[Zilliz Cloud Pricing](https://zilliz.com/pricing) を参照してください。

- データサイズ: 保存されているすべてのデータのサイズ、またはバックアップファイルのサイズをGB単位で測定します。

- 期間: データまたはバックアップファイルがZilliz Cloudに保存されている期間。

### コールドデータアクセス{#cold-data-access}

<Admonition type="info" icon="📘" title="Note">

<p>この課金項目は、Milvus 2.6.x と互換性のある階層型ストレージクラスターにのみ適用されます。</p>

</Admonition>

クラスタータイプが**階層型ストレージ**の場合、追加のコールドデータアクセス費用が発生する可能性があります。コールドデータアクセスの費用を計算する方法を以下の式で示します。

```bash
Cold Data Access Cost =  Cold Data Access Unit Price x Cold Data Size
```

- コールドデータアクセス単価: クラウドリージョンによって決定されます。詳細な料金については、[Zilliz Cloud Pricing Guide](https://zilliz.com/pricing/pricing-guide) を参照してください。

- コールドデータサイズ: 各読み取りリクエスト (検索またはクエリ) 時にスキャンされるオブジェクトストレージに保存されているコールドデータのサイズ。データサイズはGB単位で測定されます。

## 請求ルール{#billing-rules}

クラスター、ボリュームストレージの請求ルールは、バックアップストレージおよびコールドデータアクセスとは若干異なります。

- **クラスターデータとボリュームストレージ:** 1時間単位で課金され、最低1時間の料金が発生します。

- **バックアップストレージ:** 1日単位で課金され、最低1日の料金が発生します。

- **コールドデータアクセス**: 読み取りリクエスト (検索またはクエリ) ごとに課金され、最低1MBの料金が発生します。1MBを超えるリクエストは、実際にスキャンされたデータサイズに基づいて課金されます。

## 例{#examples}

ストレージコストがどのように計算されるかを理解するのに役立ついくつかの例を以下に示します。

### 例1: クラスターストレージコスト{#example-1-cluster-storage-cost}

クラスター構成が次のようになっているとします。

- **クラウドプロバイダーとリージョン**: AWS us-east-1 (バージニア)

- **クラスタータイプ**: パフォーマンス最適化

- **データサイズ**: 500 GB

- **ストレージ期間**: 29日23時間30分

クラウドプロバイダーとリージョン、およびクラスタータイプの情報から、[料金ページ](https://zilliz.com/pricing)でストレージ単価が**月額&#36;0.025/GB**であることがわかります。

[請求ルール](./storage-cost#billing-rules)により、端数時間は切り上げられ、1時間として計算されます。ストレージ期間の29日23時間30分は、30日、つまり1ヶ月に切り上げられます。

合計データストレージコストは `$0.025 x 500 × 1 = $12.50` です。

### 例2: バックアップストレージコスト{#example-2-backup-storage-cost}

クラスター構成が次のようになっているとします。

- **クラウドプロバイダーとリージョン**: AWS us-east-1 (バージニア)

- **クラスタータイプ**: パフォーマンス最適化

- **バックアップファイルサイズ**: 20 GB

- **バックアップファイル保持期間**: 44日6時間

クラウドプロバイダーとリージョン、およびクラスタータイプの情報から、[料金ページ](https://zilliz.com/pricing)でストレージ単価が**月額&#36;0.025/GB**であることがわかります。

[請求ルール](./storage-cost#billing-rules)により、端数日は切り上げられ、1日として計算されます。したがって、保持期間の44日6時間は、45日、つまり1.5ヶ月に切り上げられます。

例のクラスターの合計バックアップストレージコストは `$0.025 x 20 x 1.5 = $0.75` です。

### 例3: ボリュームストレージコスト{#example-3-volume-storage-cost}

インポートのためにボリュームに**10 GB**のデータをアップロードし、それを**1ヶ月**保持する場合、単価が**月額&#36;0.04/GB**であれば、コストは `$0.04 × 10 × 1 = $0.40` です。

### 例4: クラスターコールドデータアクセスコスト{#example-4-cluster-cold-data-access-cost}

クラスター構成が次のようになっているとします。

- **クラウドプロバイダーとリージョン**: AWS us-east-1 (バージニア)

- **クラスタータイプ**: 階層型ストレージ

- **コールドデータサイズ**: 200 GB

クラウドプロバイダーとリージョン、およびクラスタータイプの情報から、[料金ガイド](https://zilliz.com/pricing/pricing-guide)でコールドデータアクセス単価が**&#36;0.0005/GB**であることがわかります。

合計コールドデータアクセスコストは `$0.0005 x 200 = $0.1` です。

## よくある質問{#faqs}

1. **クラスターを一時停止した場合でもストレージ料金は発生しますか？**

    はい。クラスターが一時停止されている場合でも、クラスターデータ、バックアップ、またはボリュームファイルが保持されている限り、ストレージコストは発生します。

1. **ストレージに最低料金はありますか？**
 はい。ストレージには最低料金があります。

    - クラスターとボリュームストレージ: 最低1時間の料金。

    - バックアップストレージ: 最低1日の料金。
