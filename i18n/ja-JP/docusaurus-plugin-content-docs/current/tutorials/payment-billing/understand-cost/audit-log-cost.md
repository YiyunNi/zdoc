# 監査ログのコスト

[監査ログ](./audit-logs)を有効にすると、Zilliz Cloudはロギングサービスをデプロイします。これらのログの収集、処理、転送には追加のシステムリソースが消費されるため、対応する料金が発生します。

監査ログ機能の使用にかかる総コストは、以下のコンポーネントの合計です。

- [監査ログCUコスト](./audit-log-cost#audit-logs-cu-cost): 監査ログの収集と処理によって消費されるコンピューティングリソースのコスト

- [データ転送コスト](./audit-log-cost#data-transfer-cost): オブジェクトストレージへのログ転送のコスト

## 監査ログCUコスト{#audit-logs-cu-cost}

```plaintext
Audit Logs CU Cost = Audit Logs CU Unit Price x Total Number of Query CU x Audit Logs Runtime
```

- **監査ログ CU 単価**: クラスターのリージョンとプロジェクトプランによって決定されます。詳細な料金については、[Zilliz Cloud 料金ガイド](https://zilliz.com/pricing/pricing-guide)を参照してください。

- **クエリ CU の総数**: レプリカを考慮した、クラスター内のクエリ CU の総数。

    ```plaintext
    Total Number of Query CU = Query CU × Replica Count
    ```

    例えば、2つのクエリCUと2つのレプリカを持つクラスターは、合計4つのCUを持ちます。

- **監査ログのランタイム**: 監査ログ機能が有効になっている合計時間。ランタイムは`無効化時点 - 有効化時点`として計算されます。クラスターが**一時停止**状態の場合、一時停止中は監査ログ機能によってコンピューティングリソースが消費されないため、その時間は計算から除外されます。ランタイムの計算例については、[例](./audit-log-cost#example)を参照してください。

## データ転送コスト{#data-transfer-cost}

監査ログはオブジェクトストレージバケットに転送できます。現在、Zilliz Cloudは、クラスターと同じクラウドリージョンに作成されたオブジェクトストレージバケットへのログ転送のみをサポートしています。

リージョン内データ転送には、現在追加料金はかかりません。

データ転送の料金については、[データ転送](./data-transfer-cost)を参照してください。

## 例{#example}

クラスター構成が以下の通りであると仮定します。

- **プロジェクトプラン:** Enterprise

- **クラスターデプロイオプション**: Dedicated

- **クラウドプロバイダーとリージョン:** AWS us-east-1 (バージニア)

- **CUサイズ:** 8 CU

- **レプリカ数:** 2

- **監査ログのランタイム:** 

![JKGIwkjiyhRr2ebq4eKcUsZOn8d](https://zdoc-images.s3.us-west-2.amazonaws.com/JKGIwkjiyhRr2ebq4eKcUsZOn8d.png)

    上記のように、

    - 2025年8月1日12:00に監査ログが有効化されました。

    - 2025年8月1日24:00にクラスターが一時停止されました。

    - 2025年8月2日12:00にクラスターが再開され、2025年8月3日12:00に削除されるまで実行されました。

    合計ランタイムは`(24 − 12) + 24 = 36時間`です。

プロジェクトプランとクラウドプロバイダーおよびリージョン情報から、[料金ガイドページ](https://zilliz.com/pricing/pricing-guide)で監査ログの単価が**&#36;0.031/時間**であることがわかります。

CUサイズとレプリカ数情報によると、合計クエリCUサイズは`8 CU x 2 レプリカ = 16 CU`です。

監査ログの合計CUコストは`$0.031 x 16 x 36 = $17.856`です。

同一リージョン転送のため、データ転送コストは**&#36;0**です。

監査ログの合計コストは`$17.856 + $0.00 = $17.856`です。

## よくある質問{#faqs}

1. **クラスターが一時停止されている場合、監査ログの料金は発生しますか？**
いいえ。監査ログのCU料金は、機能が有効でクラスターがアクティブに実行されている場合にのみ適用されます。「一時停止」状態の時間は除外されます。

1. **監査ログを転送する際にデータ転送の料金を支払いますか？**
リージョン内転送は無料です。リージョン間転送（現在はサポートされていません）には追加料金が発生する場合があります。

1. **監査ログが有効になっているが、実際にログが生成されていない場合でも料金は発生しますか？**
はい。監査ログのCU料金は、ログが生成されたかどうかに関わらず、機能が有効な間のクラスタークエリCUサイズとランタイムに基づいて計算されます。ログが生成されない場合、データ転送コストは&#36;0になる可能性があります。

1. **ログの実際の生成量（例：高QPSワークロードと低QPSワークロード）によって課金は異なりますか？**
いいえ。監査ログのCUコストは、ログの生成量ではなく、クラスターのクエリCUサイズとランタイムにのみ依存します。
