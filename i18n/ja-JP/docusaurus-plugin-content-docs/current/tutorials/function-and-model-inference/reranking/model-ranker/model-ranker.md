# モデルベースのランカー

モデルランカーは、クエリとドキュメント間のセマンティックな関係を理解する高度な言語モデルを統合することで、Zilliz Cloudの検索を変革します。ベクトル類似性のみに依存するのではなく、コンテンツの意味とコンテキストを評価して、よりインテリジェントで関連性の高い結果を提供します。
