# AI Tools

Ready-made context prompts for AI coding assistants. Drop them into Cursor, GitHub Copilot,
JetBrains AI, or any tool that supports custom instructions to get accurate Zilliz Cloud guidance.

> **Claude Code Plugin** — Install for direct doc search inside Claude Code:
> ```bash
> claude mcp add --transport stdio zilliz-docs -- npx @zilliz-docs/zilliz-doc-search@latest
> ```
> Tools: `search_docs` · `get_doc` · `list_sections` · `search_by_section`

## Where to put these prompts

| Tool | File path |
|------|-----------|
| Cursor | `.cursor/rules/<name>.mdc` |
| GitHub Copilot | `.github/copilot-instructions.md` |
| JetBrains AI | `.jb/ai-context.md` |
| VS Code (Copilot) | `.github/copilot-instructions.md` |
| Windsurf | `.windsurfrules` |

## Direct import (Cursor, Windsurf)

Each prompt is also accessible as raw Markdown by appending `.md` to the URL.
Use the `@URL` syntax to import directly:

```
@https://docs.zilliz.com/ai-tools/python-sdk.md
@https://docs.zilliz.com/ai-tools/vector-search.md
@https://docs.zilliz.com/ai-tools/collections.md
@https://docs.zilliz.com/ai-tools/byoc.md
@https://docs.zilliz.com/ai-tools/restful-api.md
```
