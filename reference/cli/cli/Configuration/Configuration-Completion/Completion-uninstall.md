# uninstall

This operation removes shell completion from RC file.

## Synopsis\{#synopsis}

```bash
zilliz completion uninstall <shell>
```

## Options\{#options}

- **SHELL** (*string*) -

    Indicates the name of the target shell. The current shell applies if this is not specified. Possible values:

    - `bash`,

    - `zsh`,

    - `fish`.

## Example\{#example}

```bash
zilliz completion uninstall
```
