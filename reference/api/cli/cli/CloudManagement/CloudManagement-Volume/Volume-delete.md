# delete

This operation deletes a volume.

## Usage\{#usage}

```bash
zilliz volume delete [OPTIONS]
```

**OPTIONS:**

- **--name** (*string*) -

    **[REQUIRED]**

    Indicates the name of the volume to delete.

## Example\{#example}

```bash
zilliz volume delete --name my-volume
```
