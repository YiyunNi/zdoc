# describe

This operation gets the details of a project.

## Usage\{#usage}

```bash
zilliz project describe [OPTIONS]
```

**OPTIONS:**

- **--project-id** (*string*) -

    **[REQUIRED]**

    Indicates a project ID.

## Example\{#example}

```bash
zilliz project describe --project-id proj-xxxxxxxxxxxx
```
