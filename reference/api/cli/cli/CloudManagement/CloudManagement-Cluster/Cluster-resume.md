# resume

This operation resumes a suspended cluster.

## Usage\{#usage}

```bash
zilliz cluster resume [OPTIONS]
```

**OPTIONS:**

- **--cluster-id** (*string*) -

    **[REQUIRED]**

    Indicates the ID of the cluster to resume.

## Example\{#example}

```bash
zilliz cluster resume --cluster-id in01-xxxxxxxxxxxx
```
