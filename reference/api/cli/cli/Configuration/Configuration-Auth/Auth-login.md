# login

This operation logs in to Zilliz Cloud.

## Usage\{#usage}

```bash
zilliz login [OPTIONS]
```

**OPTIONS:**

- **--no-browser** (*boolean*) -

    Indicates whether to automatically open the browser.

- **--api-key** (*boolean*) -

    Indicates whether to login with an API key instead of browser.

## Example\{#example}

```bash
zilliz login
```
