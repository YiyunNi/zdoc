# uninstall

This operation removes shell completion from RC file.

## Usage\{#usage}

```bash
zilliz completion uninstall <shell>
```

**OPTIONS:**

- **SHELL** (*string*) -

    Indicates the name of the target shell. Choices: `bash`, `zsh`, `fish`. The current shell in use applies if this is not specified.
