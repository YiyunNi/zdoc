# status

This operation checks if shell completion is installed.

## Usage\{#usage}

```bash
zilliz completion status <SHELL>
```

**OPTIONS:**

- **SHELL** (*string*) -

    Indicates the name of the target shell. Choices: `bash`, `zsh`, `fish`. The current shell in use applies if this is not specified.

## Example\{#example}

```bash
zilliz completion status
```
