# show

This operation shows the completion script (for manual installation).

## Usage\{#usage}

```bash
zilliz completion show <SHELL>
```

**OPTIONS:**

- **SHELL** (*string*) -

    **[REQUIRED]**

    Indicates the name of the shell you are using. Choices: `bash`, `zsh`, `fish`.

## Example\{#example}

```bash
# check the completion command in .zshrc
zilliz completion show zsh
```
