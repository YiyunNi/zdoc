# current

This operation shows the current context.

## Usage\{#usage}

```bash
zilliz context current [OPTIONS]
```

**OPTIONS:**

- **--output, -o** (*string*) -

    Indicates the output format. Choices: `json`, `table`, `text`.

## Example\{#example}

```bash
zilliz context current
```
