# Go SDK Reference (v2)

The Go SDK v2 is maintained in the [main Milvus repository](https://github.com/milvus-io/milvus/tree/master/client). It provides a modern Go client for Milvus and Zilliz Cloud.

## Features

- **MilvusClient** — Simplified client configuration
- **Collection management** — Create, describe, list, and drop collections
- **Vector operations** — Insert, upsert, delete, search, and hybrid search
- **Index and partition management**
- **RBAC** — User and role management
- **Bulk import** — Import large-scale data

## Installation

```bash
go get -u github.com/milvus-io/milvus/client/v2
```

Then import:

```go
import "github.com/milvus-io/milvus/client/v2/milvusclient"
```

## Quick Start

```go
ctx, cancel := context.WithCancel(context.Background())
defer cancel()

milvusAddr := "YOUR_MILVUS_ENDPOINT"

cli, err := milvusclient.New(ctx, &milvusclient.ClientConfig{
    Address: milvusAddr,
})
if err != nil {
    // handle error
}
defer cli.Close()
```
